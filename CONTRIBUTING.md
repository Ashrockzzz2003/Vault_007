# Contributing to Vault 007, Mark 2 🔐

We're thrilled you're considering contributing to **Vault 007, Mark 2**! Your help makes our password manager better and more secure for everyone.

By contributing, you agree to abide by our Code of Conduct.

## How Can I Contribute?

There are many ways to contribute, not just by writing code.

### 1. Reporting Bugs 🐛

If you find a bug, please help us by submitting an issue in the **Issues** section of the repository.

* **Before submitting**, please check if the bug has already been reported.
* **Provide detailed information**:
    * A clear and descriptive title.
    * The steps to reproduce the bug.
    * The expected behavior versus the actual behavior.
    * The platform(s) affected (Android, iOS).
    * Your device model and operating system version.
    * Any relevant screenshots or logs.

### 2. Suggesting Enhancements ✨

We welcome suggestions for new features or improvements to existing ones!

* Submit a clear and detailed issue explaining the proposed enhancement.
* Explain **why** this feature would be useful to users.

### 3. Submitting Code (Pull Requests) 💻

If you're ready to dive into the code, follow these steps to submit a Pull Request (PR):

1.  **Fork** the repository and clone your fork.
2.  **Create a new branch** for your feature or fix (e.g., `feature/tag-filter` or `fix/crash-on-search`).
3.  **Make your changes.** Ensure your code adheres to the project's style and conventions.
4.  **Test your changes** thoroughly on the relevant platforms (Android/iOS).
5.  **Commit your changes** with clear and descriptive messages. A good commit message explains **what** you changed and **why**.
6.  **Push** your branch to your fork.
7.  **Open a Pull Request** against the `main` branch of the original repository.
    * Reference the issue your PR addresses (e.g., `Closes #123`).
    * Provide a clear summary of the changes.

## Getting Assigned to an Issue

If you want to work on an existing issue, please leave a comment on the issue asking to be assigned.

**Important**: To ensure you are assigned to an issue, please **tag the developer** in your comment: `@Ashrockzzz2003`.
